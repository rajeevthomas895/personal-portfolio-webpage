# Personal Portfolio Webpage

A personal portfolio webpage built with HTML and CSS as part of the freeCodeCamp Responsive Web Design Certification.

## About the Project

This project was completed as part of the freeCodeCamp Responsive Web Design Certification.

freeCodeCamp provided the project requirements and user stories, while I completed the HTML and CSS implementation for a personal portfolio webpage.

The page includes an introduction section, project showcase, navigation bar, and contact links.

## Features

- Fixed navigation bar
- Welcome section
- Projects section
- Project cards with images and links
- GitHub profile link
- Email contact link
- Hover effects
- Full-screen welcome section
- Responsive web design structure

## Built With

- HTML
- CSS
- Font Awesome icons

This project helped me practice:

- HTML page structure

- CSS Grid

- Full viewport sections

- Navigation links
